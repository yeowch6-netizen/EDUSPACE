Open index.html on a modern browser.

PC/LAPTOP: Extract the ZIP, then open index.html.

MOBILE: For the smoothest experience, upload the extracted files to a static HTTPS host and open the page on your phone. You can then use Add to Home Screen / Install. Some phones restrict local HTML files.

SAVING: Tasks and resources use IndexedDB and are saved locally in the browser/device. There is no account, online database, cloud sync, or automatic sharing between devices.
